Gerir acessos ao MIXMIND

Modo GitHub (sem servidor): quem pode entrar na app está no ficheiro acessos.json do repositório. Esta página gera as entradas — a palavra-passe é transformada aqui, no teu navegador, num hash PBKDF2-SHA256 (600 000 iterações, sal aleatório) e nunca é guardada nem enviada.

O acessos.json fica público no GitHub (só com hashes). Usa palavras-passe longas e únicas para o MIXMIND — nunca as do banco ou do email.

2 · Acessos atuais

Carregado do acessos.json publicado (podes colar outro em baixo). Desativar ou remover alguém tem efeito na próxima vez que a app for aberta (até ~10 min de cache do GitHub).

3 · Publicar no GitHub

Abrir acessos.json no GitHub para editar →
  1. Copia o conteúdo.
  2. No GitHub, abre acessos.json → lápis (Edit) → apaga tudo → cola.
  3. “Commit changes”. Em cerca de 1 minuto o acesso funciona na app.
